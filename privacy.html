LifeOS Privacy Policy

Last updated: 30 October 2026

What LifeOS does

LifeOS uses YouTube API Services to upload videos, set their titles, descriptions, tags and publish times, and read basic statistics for YouTube channels owned by the LifeOS owner.

Data accessed

When a channel owner grants access, LifeOS receives an OAuth token for that channel. It uses the token only to upload and manage that channel's own videos and to read the channel's public details and statistics.

Storage and sharing

OAuth tokens are stored only on devices controlled by the LifeOS owner. LifeOS does not sell, share or transfer any user data to third parties and does not use it for advertising.

Revoking access

Access can be revoked at any time from the Google account security settings: myaccount.google.com/permissions.

Third-party terms

LifeOS uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Contact

Questions can be raised through this site's GitHub repository.
